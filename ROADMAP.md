# Lantern Line roadmap

Each milestone is a set of small tasks in work/, one file each. A milestone is done when
every task in it has merged with its tests passing.

## M1 · Core loop

Ghosts have health, arrive in waves, and the game can be won, lost and restarted.

## M2 · Towers and targeting

A second tower with splash damage, a visible range, and a choice of first or nearest target.

## M3 · Waves and economy

Gold for each ghost defeated, towers that cost gold, and waves that grow from a table.

## M4 · HUD and polish

A HUD with lives, gold and wave, pause and speed controls, and a start screen, following
design/hud.md.
